技术学习心得分栏

这里用于持续记录编程学习过程中的知识沉淀、实践总结、踩坑复盘与工具使用心得。

内容按专题分栏整理，方便后续系统复习，也适合作为个人技术成长轨迹展示。

前端开发

记录 HTML、CSS、JavaScript、框架原理、页面性能优化和工程化经验。

  • 页面布局与响应式设计
  • Vue / React 学习心得
  • 构建工具与前端工程化

后端开发

整理服务端开发、接口设计、数据库建模、缓存与部署实践相关内容。

  • RESTful API 设计
  • 数据库与 SQL 总结
  • 项目部署与运维入门

算法与数据结构

沉淀刷题思路、常见题型模板、复杂度分析与复盘记录。

  • 数组 / 链表 / 栈队列
  • 二叉树 / 图 / DFS / BFS
  • 动态规划与贪心策略

AI 与自动化

记录 AI 工具使用、提示词设计、自动化工作流和效率提升尝试。

  • Copilot / LLM 使用笔记
  • Prompt 设计与实践
  • 脚本自动化方案

开发工具

汇总 Git、GitHub、VS Code、终端工具和常用效率插件的使用心得。

  • Git 工作流与版本管理
  • 编辑器配置与插件推荐
  • 命令行效率技巧

学习复盘

定期回顾近期输入与输出，形成可持续迭代的学习节奏。

  • 周总结 / 月总结
  • 项目复盘
  • 知识体系整理

建议的写作模板

  1. 这次学了什么
  2. 核心知识点有哪些
  3. 实际操作中遇到了什么问题
  4. 如何解决
